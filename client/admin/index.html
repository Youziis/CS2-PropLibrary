截图流程

  1. 勾选需要截图的道具（可以使用上方的快捷按钮批量选择）
  2. 点击"保存选择并准备截图"按钮
  3. 启动 CS2 游戏，进入对应地图
  4. 开启控制台输入：sv_cheats 1
  5. 运行截图工具：python screenshot.py
  6. 截图完成后运行：python create_screenshot_index.py
  7. 前往"审核道具"页面查看截图并进行审核

导出后续步骤

1. 使用 Git 推送更新

  • 打开终端或 GitHub Desktop
  • 查看更改的文件
  • 输入提交信息（如："添加了 5 个新道具"）
  • 点击 Commit → Push

2. Cloudflare Pages 自动部署

  • 推送后 Cloudflare 会自动检测
  • 等待 1-2 分钟部署完成
  • 访问你的网站查看更新
